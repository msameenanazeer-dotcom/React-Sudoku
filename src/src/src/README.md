# 🧩 Sudoku React Game

A simple Sudoku game built using React and Vite.

## Features

- 9 × 9 Sudoku board
- Enter numbers from 1 to 9
- Check your solution
- Automatically solve Sudoku
- Reset the puzzle
- New Game button
- Responsive design

## Technologies

- React
- JavaScript
- HTML
- CSS
- Vite
